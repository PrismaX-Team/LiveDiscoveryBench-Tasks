设计哲学

一个能够持续向前的 Benchmark

01

Live Question

评测的不是解决办法明确的静态题目，而是仍未解决、并值得不断推进的真实前沿问题。

02

Live Environment

在开放环境下，模型可以检索调研问题的前沿方法，公开前沿是研究的起点，而不是需要隔离的信息。

03

Live Metric

评分规则固定，但比较坐标持续更新；每个结果都相对于其他 Agent 和当前前沿进行衡量。

04

Live Community

Benchmark 不是一次性封闭发布的题库，而由研究者、领域专家等贡献者持续共同发现、构建和完善。

05

Innovation

评测关注的不是完成既定步骤，而是 Agent 能否把调研转化为经过验证的改进，在尚未解决的科学问题上取得可衡量的进展。

06

确定性验证

Verifier 在运行前冻结，并在离线环境中评分；相同的冻结输入、Validation 历史、Context 和提交必须得到相同结果。

07

受控评测

资源和网络边界预先固定，研究过程被完整记录与审计，防止 hacking、访问隐藏输入或通过绕过约束获得虚假高分。

任务实例

蛋白稳定性：三轮突变筛选

生物医学

面向 10 个匿名蛋白进行三轮单点突变筛选，从返回的实验测量中持续学习，并给出已测与未测两类最终候选。

查看任务↗

Instruction

筛选 10 个匿名蛋白的单点突变，实验测得的 ddG 越低越好，小于 0 表示突变后更稳定。进行三轮筛选：每轮为每个蛋白选择 16 个新候选，共 160 个，并根据返回的实验测量改进下一轮选择。最终为每个蛋白推荐 8 个已测候选和 8 个未测候选，并说明策略如何随三轮结果变化。

可以调研论文、算法和一般研究方法，但不得检索本题来源数据或隐藏实验测量。

Input

10个匿名蛋白

3,953个候选突变

399条先导测量

任务开始时还会提供实验说明、质量控制信息和筛选约束。

Verifier

Validation

检查每轮提交的 160 个新候选，并返回对应的实验测量。

Test

检查最终提交，并计算 0–100 的任务得分。

Environment

无额外任务依赖

Meta

领域
生物医学
得分
0–100，越高越好
数据来源
蛋白折叠稳定性大规模实验研究↗Tsuboyama 等人处理后的蛋白稳定性数据集 v2_230420↗
