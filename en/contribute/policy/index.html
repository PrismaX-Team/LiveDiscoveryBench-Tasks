Contribution policy

These incentives apply only after a task package is accepted into Science Innovation Exam, not when a Proposal is opened.

Start a proposalBack to contribute
01

Co-authorship

Contributors of at least one accepted task package can be listed as co-authors on the project paper. They must help complete verification, revisions and author-information confirmation.

02

Reviewer and core maintainer path

Members with more than four accepted task packages may be invited to review tasks and join the core maintainer path. This is an invitation, not an automatic promotion.

Proposal review, dual review and repository gates stay in force. Bodies, links and comments remain public.
