Design philosophy

A benchmark designed to keep moving

01

Live Question

The benchmark targets real frontier questions whose solutions remain open and worth advancing—not static problems with known solution paths.

02

Live Environment

Agents can investigate frontier methods in an open environment. Public knowledge is the starting point of research, not information to isolate.

03

Live Metric

Scoring rules stay fixed while the comparison frame keeps moving; every result is measured against other agents and the current frontier.

04

Live Community

The benchmark is not a closed, one-off task set. Researchers, domain experts and other contributors continuously discover, build and improve it together.

05

Innovation

The benchmark measures whether an agent can turn investigation into a tested improvement that makes measurable progress on an unresolved scientific problem.

06

Deterministic verification

The verifier is frozen before a run and scores offline. The same frozen input, validation history, context and submission must produce the same result.

07

Controlled evaluation

Resource and network boundaries are fixed, and the research process is recorded and audited to prevent hacking, hidden-input access and invalid high scores.

Task example

Protein stability: a three-round mutation campaign

Biomedicine

Across three feedback rounds, select single-amino-acid mutations for ten anonymized proteins, learn from returned measurements, and recommend validated and prospective variants.

View task↗

Instruction

Screen single-amino-acid mutations for ten anonymized proteins, where lower measured ddG is better and values below zero indicate improved stability. Run three rounds: in each round, select 16 new variants per protein—160 in total—and use the returned measurements to improve the next selection. Finally, recommend eight measured and eight unmeasured variants per protein and report how the strategy changed across the campaign.

Research papers, algorithms and general methods may be consulted; the source dataset and hidden measurements may not be retrieved.

Input

10anonymized proteins

3,953candidate mutations

399pilot measurements

Assay guidance, quality-control information and campaign constraints are provided at the start.

Verifier

Validation

Checks each round's 160 new candidates and returns their experimental measurements.

Test

Checks the final submission and computes the 0–100 task score.

Environment

No task-specific dependencies

Meta

Domain
Biomedicine
Score
0–100, higher is better
